    Shortcuts you can use here

    Keys work while the mouse is over the workspace, just like Blender sends keys to the editor under the pointer.

    LMB
    Select a keyframe or handle · Shift to add · drag to move · drag on empty space to box-select
    G · X / Y
    Move the selected keys; X only in time, Y only in value. Click or Enter to confirm, Esc to cancel.
    A · AltA
    Select all / none
    I
    Insert a keyframe on the active channel at the current frame
    X · Delete
    Delete the selected keyframes
    T
    Interpolation Mode: Constant, Linear, Bezier
    V

    BACK IN BLENDER

    The same bounce in Blender

    This lab shows a simplified Blender: one object, a side camera and a few channels. The curves, handles and keys behave like Blender's F-curves.

    1. Add a UV Sphere, set its origin to the bottom (Object › Set Origin or move the mesh up) so it squashes against the floor.
    2. Open the Animation workspace. At frame 1 press I › Location with the ball up; key the contacts and the tops.
    3. In the Graph Editor, select all and press T › Bezier; select the contacts and press V › Vector.
    4. Make every bounce lower and shorter. Turn on Motion Paths (Object properties) to see the spacing.
    5. Key Scale for squash and stretch, or add a Maintain Volume constraint.
    6. Shape weight with the handles: long at the top for light objects, short and sharp for heavy ones.
