BACK IN BLENDER

Try the same idea in Blender 5.2

The lab shows the idea with a paper cube. In Blender, you can mark seams and let Unwrap make a UV layout.

  1. Enter Edit Mode and switch to Edge Select.
  2. Select edges and choose Edge → Mark Seam.
  3. Select the faces and choose UV → Unwrap.
  4. Inspect the result in the UV Editor.
